# 모아 (MOA)

퀴즈, 워드클라우드, 열린 질문으로 수업과 행사 참여자의 생각을 한 화면에 모으는 한국어 실시간 참여 웹앱입니다.

## 주요 기능

- 6자리 코드 기반 세션 생성 및 참여
- 라이브 퀴즈와 결과 집계
- 워드클라우드 응답 수집
- 익명 열린 질문
- 진행자·참여자 반응형 화면
- Cloudflare D1 기반 세션·활동·응답 저장
- 글래스모피즘과 파스텔 네오브루탈리즘 디자인

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증:

```bash
npm test
npm run lint
```

데이터베이스 스키마를 변경한 뒤에는 `npm run db:generate`로 마이그레이션을 생성합니다.

## 기술 구성

Next.js 16, React 19, vinext, Cloudflare Workers, D1, Drizzle ORM으로 구성되어 있습니다.

## 운영 참고

아키텍처는 200명 이상의 참여자가 응답을 전송하는 읽기·쓰기 패턴을 고려했습니다. 실제 운영 전에는 목표 네트워크와 행사 조건에서 별도 부하 테스트를 권장합니다.
